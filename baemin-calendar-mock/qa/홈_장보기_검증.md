# 홈·장보기 확장 검증

2026-10-26. 실제 주문·결제는 없으며 모두 로컬 시연이다.

## 댓글 반영

1. 캘린더 상단 ‘음식 기록’ 버튼 제거. `.calendar-caption button` 없음.
2. 예전 QA 저화질 비빔밥 사진은 해당 데모 이름·출처·작은 이미지 조건에서만 선명한 시연 사진으로 표시. 기존 저장 원본/사용자 일반 사진은 변경하지 않음.
3. 우측 제어판·내역 하단·헤더·이전 홈의 직접 가상 주문 생성 버튼 제거. `[data-action="new-order"]` 없음. 메뉴/상품을 장바구니에 담은 후 주문하기로만 새 주문 생성. 주문내역 재주문은 홈의 해당 가게로 이동.
4. 촬영 등록은 캘린더 날짜를 선택해 열린 날짜 시트에서만 제공. 날짜를 선택하지 않은 상태의 전역 사진 등록 버튼은 0개. 마이배민은 캘린더로 안내.

## 확장

- 음식 메뉴 26개, 주문 가능한 음식 가게 9개 + 준비중 가게 1개.
- 장보기·쇼핑 4개 매장, 상품 16개. 매장/카테고리/검색으로 조회.
- 가게 메뉴, 메뉴/상품 상세, 수량 선택, 한 가게 장바구니, 수량 변경/삭제, 최소주문금액 확인, 주문과 상태 진행을 연결.
- 장바구니 별도 저장. 다른 가게 상품을 담을 때 기존 장바구니 교체 안내.
- 구매/식사 구분: 장보기는 ‘장보기·쇼핑’ 내역으로 조회하며 주문 캘린더 및 식사 영양 합계에서 제외.
- 픽업 선택은 주문의 fulfillment로 저장. 상태 문구를 픽업 대기/픽업 완료로 구분.

## 직접 확인

- 홈 피자 카테고리 선택 → 페퍼로니 피자 상세 → 2개 담기 → 37,800원 장바구니 → 주문 → 세 단계 진행 → 배달 완료.
- 완료 피자 주문이 한국 날짜 10월 26일 캘린더에 표시됨. 주문 상세의 시각도 2026-10-26 04:08로 한국 시간 표기 확인.
- 장보기 우유·계란 필터에서 상품 4개 표시 → B마트 우유 1개/계란 1개 → 7,960원 주문 → 상품 준비/배송/배송완료 → 별도 구매내역 확인.
- 장보기 완료 카드에 식사 기록 버튼 없음. 상세에서도 식사 영양 블록을 숨김.
- 캘린더 날짜 → ‘음식 촬영·등록’ → 기존 사진 입력/분석 폼이 열림.
- 개선 사진의 background-image가 새 음식 사진을 참조하며 상단/하단의 삭제 대상 버튼이 없음.
- 넓은 화면 가로 넘침 없음. 콘솔 오류 없음. 이번 별도 검증 탭에서는 임시 viewport 설정이 실제 폭에 적용되지 않아 정확한 휴대전화 크기의 새 흐름 검증은 별도로 남김. 임시 설정은 reset 처리.
- JS 테스트 14개 + Python 테스트 5개, 총 19개 통과. JS 구문·Python 컴파일 확인.

## 근거와 한계

홈은 이전 실제 앱 캡처 R02/R12 및 실기 조사 참고. 장보기는 이전 조사에서 확인한 검색·매장·프로모션·가게 분류를 참고해 설계했으며 이번 미러링 입력은 실패해 새 상세 탐색은 하지 못함. 개인화 광고·실시간 가격/재고·실제 주문 API를 재현한 것은 아니다.

홈 음식 카테고리는 시스템 컬러 이모지와 CSS, 매장 로고는 CSS로 구성. 음식/상품 사진은 생성한 시연 에셋이다. [에셋·전체 프롬프트](../assets/README.md).
