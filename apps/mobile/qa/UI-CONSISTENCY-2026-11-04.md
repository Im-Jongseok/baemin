# 배민 화면 통일성 보완

## 비교 근거

- iPhone 미러링에서 사용자가 열어 둔 실제 배민 홈을 확인했다. 연한 민트 헤더, 흰 검색창, 주소 옆 화살표, 검정 배민클럽 배지, 서비스 선택 밑줄, 중립색 필터를 참고했다.
- 주문내역·마이배민은 2026-10-26에 보존한 실제 앱 캡처와 비교했다. 이번 확인에서 실기기의 해당 화면들을 직접 이동한 것은 아니다.
- 이전 웹은 유지하고 Flutter 공통 테마와 관련 화면만 수정했다. 계절 캠페인·로딩 영역은 복제하지 않았다.

## 변경

- 기본 Material 색조 대신 흰색·검정·중립 회색·민트로 공통 버튼/선택 칩/분량 선택/입력창/대화상자를 통일했다.
- 선택 칩의 한글 글꼴과 흰 글씨를 명시해 렌더 캡처에서 발견한 글자 깨짐을 수정했다.
- 홈 헤더·검색창·서비스 밑줄·배민클럽 배지를 실제 화면에 가깝게 조정했다.
- 과일·채소 바로가기의 Apple 회사 로고를 기존 과일 사진으로 교체했다. 알 수 없는 최소주문 금액은 0원으로 표시하지 않는다.
- 마이배민 프로필 크기·여백과 공통 구분선을 조정했다. 쿠폰 배너의 흰 글씨로 대비를 높였다.
- 강한 보라색 쿠폰, 유리 효과 하단 메뉴, 만보기 배경, 기존 글자 가독성 보정은 유지했다.

## 검증

- Flutter 80개, 기존 웹 46개, Python 13개 테스트 통과. 마지막 칩 글꼴 수정 뒤 Flutter 전체 80개를 다시 확인했다. Dart 정적 분석 오류 없음.
- 360/393/430px 화면과 카테고리 진입·브랜드 선택·장바구니·사진 분량 선택 흐름을 기존 테스트로 확인했다.
- `qa/flutter-tab-0.png`, `qa/category-fastfood.png`, `qa/photo-analysis-review.png` 등은 실제 Flutter 위젯 렌더 캡처다. 사진 분석 캡처는 통제된 응답이며 외부 모델 성공 증거가 아니다.
- Flutter 웹 release 빌드를 4181에서 제공한다. 브라우저 자동 조작이 설정에서 비활성화돼 이번 검증은 위젯 렌더와 HTTP 응답 기준이다.
- iPhone 설치는 사용자의 기존 요청대로 보류한다. 실기기에서 이번 UI 변경을 설치해 확인한 것은 아니다.
- HF 요금은 공식 PRO·Inference Providers 문서로 재확인했다. 크레딧 충전이나 추가 실제 추론은 실행하지 않았다.
