# 현재 목업의 화면 전환과 앱 전환 비용

2026-10-26. 현재 범위: 홈·상품/가게 탐색·장바구니·가상 주문·상태 진행·캘린더·사진 등록·리포트·시연 쿠폰. 실제 배민 제휴·주문·결제·사용자 계정·실서비스 운영은 별도다.

## 이번 반영

- 시연 제어판 DOM과 관련 버튼/이벤트/분기 표시 제거. 주문·식사·쿠폰·장바구니 저장 데이터 유지.
- CU·GS25의 잘못된 왼쪽 절단 좌표를 교정. 전체보기 원본 이미지는 상단 배지까지 포함해 재절단하고 같은 높이/기준선으로 배치.
- 홈 배너는 포케 사진·기록 카드 시각과 ‘식습관 리포트’ 진입점으로 보완.
- 메뉴/상품 상세, 장바구니, 주문상세는 휴대폰 영역 전체 화면으로 전환한다. 기존 배경·탭은 비활성 처리하고 상단 뒤로가기와 브라우저 이력을 연결했다. 사진/쿠폰/확인 같은 보조 작업은 기존 대화상자를 유지한다.
- 화면 전환은 Web/Flutter/네이티브 모두 가능한 UI 패턴이다. 현재 웹 구현을 위해 프레임워크를 교체할 필요는 없다.

## 공수 추정

다음은 이 코드와 구현 범위를 보고 산정한 **경험 있는 개발자 1명 기준의 계획용 추정**이다. 시장 평균/외주 확정 견적이 아니며, 개발 속도·품질·접근성·기기 검증 수준에 따라 변한다. UI는 현재처럼 주어진 상태라고 가정한다. 인일은 개발자 1명이 하루 일하는 양이며 자동화 에이전트 실행 시간을 의미하지 않는다.

| 경로 | 현재 목업을 재사용하는 부분 | 예상 추가 공수 | 예시: 40만원/인일 가정 |
| --- | --- | --- | --- |
| 웹 목업 계속 개선 | HTML/CSS/JS·에셋·상태·로컬 서버 대부분 | 화면 전환·세부 보정·검증 0.5~2인일 | 20~80만원 |
| Flutter로 iOS/Android 시연 앱 | 에셋·데이터/규칙 설계·서버 재사용. 화면/상태 코드는 Dart로 이식 | 5~10인일 | 200~400만원 |
| iOS 네이티브 시연 앱 | 에셋·규칙 설계·서버 재사용. SwiftUI/UIKit 화면 재작성 | 5~10인일 | 200~400만원 |
| iOS+Android 네이티브 별도 | 각 플랫폼 화면/내비게이션/권한/저장 구현 | 10~20인일 | 400~800만원 |

단가는 계산 예시다. 실제 외주 범위/공급자 견적을 조회하지 않았으며 학습 기간·신규 디자인·기기 구매·부가세·수정 계약·유지보수는 포함하지 않았다. 로그인·서버 DB·실제 음식 모델 평가·실제 결제·상품 재고·배민 정식 데이터 제공은 위 범위에 없다.

발표/UX 검증 목적이면 웹을 유지하는 것이 현재 코드 재사용 면에서 가장 적은 추가 작업이다. 여러 사람의 휴대폰에 설치해 촬영/동작을 반복 검증할 때 Flutter를 검토할 수 있다. iOS 플랫폼 고유 동작이 핵심이고 한 플랫폼에 집중한다면 iOS 네이티브가 후보가 된다. 이번 요청만으로 Flutter나 네이티브 프로젝트를 새로 만들지는 않았다.

## 도구와 배포의 고정 비용 (공식 문서 확인)

- Flutter는 무료 오픈소스다. [Flutter FAQ](https://docs.flutter.dev/resources/faq).
- App Store 배포용 Apple Developer Program은 연 99 USD(가능한 지역은 현지 통화)다. 로컬 테스트/개발과 앱스토어 배포를 구별한다. [Apple 프로그램](https://developer.apple.com/programs/).
- Google Play Console 등록은 25 USD 일회성이다. 계정 유형에 따른 검증/테스트 요건은 별도다. [Google Play 안내](https://support.google.com/googleplay/android-developer/answer/6112435?hl=en).
- 사진 분석 모델·호스팅·기타 API 비용은 선택한 서비스와 호출량에 따라 별도 산정한다. 실제 HF 호출은 여전히 미검증이다.

## 검증 상태

- 최신 코드의 JS 구문/Python 컴파일, 기존 자동 테스트 26개 통과.
- 추출 PNG 25개 재생성 및 잘림을 원본 비교 이미지로 확인. 정적 파일 HTTP 확인.
- 이번 브라우저 검증은 도구가 ‘Local browser use is disabled in Work settings’로 차단되어 실행하지 못했다. 새 화면 전환/뒤로가기/정렬에 대한 직접 클릭·최종 렌더 검증이 남아 있다. 다른 도구로 설정 제한을 우회하지 않았다.
