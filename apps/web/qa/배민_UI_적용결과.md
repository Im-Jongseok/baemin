# 배민 UI 적용 결과

2026-10-26. 대상은 주문내역·찜·마이배민이다. 주문 캘린더와 사진 기록은 제안 기능으로 추가했다. 실제 앱과 픽셀 단위로 동일하다는 의미는 아니다.

| 영역 | 관찰 근거 | 적용 |
| --- | --- | --- |
| 공통 | P01·P02·P09 | 흰색/연회색 배경, 상단 제목·장바구니, 배달·픽업 탭, 둥근 하단 메뉴바, SVG 아이콘·선택 표시 |
| 주문내역 | P02·P06 | 검색·조회기간·상태 컨트롤, 음식사진/가게/주문상세, 보라색 결제금액, 리뷰·같은 메뉴 담기·바로 주문 |
| 찜 | P09 | 가게 수, 사진·준비중 표시, 별점, 보라색 배달팁, 최소주문·픽업 표시 |
| 마이배민 | P01 | 캡처 기반 프로필 배경 제거 PNG, 쿠폰·포인트·선물함·결제수단, 급식표·찜 미리보기, 한 끼 기록 추가 |
| 사진 | P09 스타일 참조 | 음식별 2×2 시연 사진 제작. 측정·영양분석 근거로 사용하지 않음 |

## 확인

- 기존 자동 테스트 14개 통과. 앱 JS 구문 및 서버 Python 컴파일 확인.
- 브라우저에서 주문내역·찜·마이배민 렌더링, 프로필 이미지, 검색 결과, 전체취소 필터, 주간 전환을 확인.
- 국수 검색 시 국수 주문 하나만 표시하고 전체 영양 합계는 숨김.
- 전체취소 주문에서 식사 기록 버튼·영양 합계가 나오지 않음.
- 좁은 화면과 넓은 화면에서 document 폭이 viewport 폭과 같음. 임시 화면 크기 변경은 초기화.
- 메뉴 사진 background-position을 종류별로 분리해 기존 카드 배경 스타일과의 충돌 수정.
- PNG 경로 HTTP 200, 서버 소스 HTTP 404. 브라우저 콘솔 오류 없음.
- 조회기간은 월 선택 구현 및 코드 확인 완료. 마지막 UI 확인 중 브라우저 댓글 입력 모드가 클릭을 가로채 월 적용까지의 직접 검증은 완료하지 못함.

## 범위

홈 전체·장보기·결제수단·고객센터 등은 실제 앱 전체를 재현한 것이 아니다. 해당 메뉴는 안내를 제공한다. 실제 Baemin API와 Hugging Face 실호출 상태는 이전 단계와 같다. 저장한 가상 주문·식사 기록은 유지한다.
