# 배민이지 미러링 관찰 · 2026-10-26

사용자가 띄운 배달의민족 B마트 화면을 CUA native iPhone Mirroring으로 직접 관찰했다. REA 엔진/네트워크 API 분석은 수행하지 않았다.

표시 가격은 해당 매장·관찰 시점의 값이다. 우유 화면의 배민클럽 10% 쿠폰은 관찰했지만 발급/사용하지 않았고 목업의 기존 쿠폰 조건을 변경하지 않았다. 실제 주문/결제/장바구니 추가는 수행하지 않았다.

영양성분표는 확인하지 못했다. 세 상품 모두 nutrition:null로 저장하며 건강·영양 균형 추천 근거로 사용하지 않는다. 국·탕을 건강식으로 분류하지 않는다. 메뉴명만으로 영양소 함량을 추정하지 않는다.

사진은 정사각형 비율을 유지한다. 원본 전체 화면과 해시 manifest는 HTTP 공개 대상에서 제외한다. 돼지국밥 사진은 검색 타일 해상도만 확보했다. 두부 사진/가격은 이번 미러링 관찰 대상이 아니다.

JS 45개·Python 5개 통과. 이번 화면 시각 검증은 Work의 로컬 브라우저 비활성화로 수행하지 못했으며 HTTP와 렌더 함수 출력 검증을 별도로 수행했다.
