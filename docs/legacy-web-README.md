# 한끼록

음식 사진 캘린더와 주간·월간 영양 리포트를 제공하는 반응형 웹 페이지입니다.

## 실행

이 폴더에서 `python3 -m http.server 4173`을 실행한 다음 http://localhost:4173 에 접속합니다. 별도 패키지 설치나 빌드가 필요하지 않습니다.

## 기능

- 월 이동, 오늘 이동, 날짜별 식사 사진과 칼로리 조회
- 식사 기록 추가 및 삭제, 사진 업로드와 축소 저장
- 날짜·음식 이름·가게·식사 유형·칼로리·탄수화물·단백질·지방 입력
- 선택한 날짜가 포함된 주(월요일 시작) 또는 월의 합산 리포트
- 칼로리 막대 그래프, 영양소 에너지 비율 도넛 그래프
- 브라우저 localStorage에 기록 보관
- 모바일·태블릿·데스크톱 반응형 화면

## 데이터 기준

처음에는 현재 월의 예시 기록이 표시됩니다. 예시 음식 사진은 Unsplash의 연출 이미지로 실제 메뉴와 다를 수 있습니다. 예시 영양 수치는 구현 확인용입니다. 사진과 웹 폰트 로드에는 인터넷이 필요하며 사진 로드 실패 시 기본 이미지가 표시됩니다.

영양 수치는 사용자가 직접 입력합니다. 주문 내역 연동, 사진 AI 분석, 서버 저장, 계정 간 동기화는 포함하지 않습니다. 평균은 기록이 있는 날짜 수로 나누며 전체 식사 섭취량을 의미하지 않습니다. 영양소 비율은 탄수화물·단백질 4 kcal/g, 지방 9 kcal/g 환산값을 기준으로 하므로 입력 칼로리와 차이가 날 수 있습니다.

사진은 최대 5MB의 JPEG/PNG/WebP를 받아 최대 900px JPEG로 축소합니다. 브라우저 저장 공간이 가득 차면 오류를 표시합니다. 사이트 데이터 삭제 시 기록도 삭제되며 브라우저/접속 주소별로 별도 보관됩니다.

## 확인

JavaScript 구문 검사 및 브라우저에서 초기 렌더링, 주·월 전환, 식사 추가, 합산 갱신, 새로고침 후 저장 유지, 삭제, 리포트 화면 전환을 확인했습니다.

## 2026-09-15 디자인 참조 적용

사용자가 제공한 Baemin Reference Design System을 참고해 밝은 민트 `#0cefd3`, 흰색/연회색 표면, 검정 본문, 평면 카드 및 간결한 한국어 문구를 적용했습니다. 영양 차트의 검정/회색 구분은 이 페이지의 자체 범례이며 공식 영양 의미 색상을 주장하지 않습니다. 카드·폼·캘린더는 자체 웹 컴포넌트로, 공식 배민 앱의 복제 컴포넌트가 아닙니다.

390px 너비, 최상단 캘린더, 민트 dots와 스와이프는 유지됩니다. WORK 바이너리는 제공되거나 번들되지 않았습니다. 설치된 BAEMINWORK가 있으면 사용하고, 없으면 웹 미리보기용 OS 글꼴로 표시합니다. 이는 WORK 렌더링 검증을 의미하지 않습니다. 외부 Google Fonts 로드는 제거했습니다.

브라우저에서 너비 390px, 캘린더 상단 위치 12px, 수평 넘침 없음, dots 클릭 시 사진 전환을 확인했습니다.
